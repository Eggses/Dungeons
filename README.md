Dungeons

Dungeons will clone a template world and load it into the game with a unique name. Players can enter this world while its portal is open. Once the portal is closed, no one else can enter. Dungeons can have speical gameplay rules and events. In response to running, or pressing specific buttons, presure plates, or levers, code can be executed. Dungeons end once all players leave the dungeon either by leaving through the portal or by logging out. Upon end, the world is deleted. If the server is stopped, the world is not deleted but will be deleted once the plugin is loaded again.
